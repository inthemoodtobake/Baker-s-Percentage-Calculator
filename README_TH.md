# Baker's Percentage Calculator

เว็บแอปแบบ Static สำหรับคำนวณน้ำหนักวัตถุดิบด้วย Baker Percentage และแชร์ลิงก์ให้ผู้อื่นใช้งานได้

## ฟังก์ชันหลัก
- กำหนดน้ำหนักโดว์ต่อโลฟและจำนวนโลฟแบบจำนวนเต็ม
- แยกหมวด Flour ออกจากส่วนผสมอื่น
- แป้งหลักปรับเปอร์เซ็นต์คงเหลืออัตโนมัติ เพื่อให้แป้งทุกประเภทรวมกันเท่ากับ 100%
- เพิ่มหรือลบประเภทแป้งและส่วนผสมได้
- ทุกครั้งที่เปิดหรือรีเฟรชหน้าเว็บ ระบบจะแสดงสูตร Original
- สลับภาษาไทยและอังกฤษได้
- พิมพ์หรือบันทึกเป็น PDF
- รองรับการใช้งานบนคอมพิวเตอร์และโทรศัพท์มือถือ

## สูตร Original
- Bread Flour 100%
- Water 70%
- Liquid Starter 30%
- Salt 2%
- น้ำหนักโดว์ต่อโลฟ 650 กรัม
- จำนวนโลฟ 1 โลฟ

## วิธีทดลองบนเครื่อง
ดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดด้วยเว็บเบราว์เซอร์

## วิธีนำขึ้น GitHub Pages
1. สมัครหรือเข้าสู่ระบบ GitHub
2. สร้าง Repository ใหม่แบบ Public เช่น `bakers-calculator`
3. อัปโหลดไฟล์ `index.html`
4. ไปที่ Settings > Pages
5. Source เลือก Deploy from a branch
6. เลือก Branch `main` และโฟลเดอร์ `/root`
7. กด Save ระบบจะสร้างลิงก์ลักษณะ `https://ชื่อผู้ใช้.github.io/bakers-calculator/`
